# Portfolio

Personal engineering portfolio of Asad Imran, an electronics, embedded systems and FPGA engineer.

Live site: https://asadimranrafique.github.io/portfolio/

Built with plain HTML, CSS and JavaScript. No framework, no build step.

## Run locally

```
python -m http.server 8000
```

Then open http://localhost:8000.

## Deploy

Hosted on GitHub Pages from the root of the `main` branch.
